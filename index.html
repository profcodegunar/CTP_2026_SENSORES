Sensores aplicados a cámaras de seguridad

Manual técnico interactivo para comprender los sensores utilizados en videovigilancia y reproducir su lógica de detección mediante Arduino UNO, sensor ultrasónico, semáforo LED y buzzer piezoeléctrico.

Objetivo de la sesión

Competencia a desarrollar

El estudiante reconocerá los principales sensores y métodos de detección presentes en sistemas de videovigilancia, diferenciará detección física de análisis de video y construirá un prototipo de alerta por distancia con Arduino UNO.

Enfoque técnico: no se estudia el sensor de forma aislada. Se analiza como parte de un sistema: detección, procesamiento, decisión, alarma y registro.
Fundamentos

1. Sensores y detección en videovigilancia

Una cámara de seguridad moderna puede incorporar sensores físicos, entradas de alarma y funciones de análisis de imagen. El instalador debe distinguir estos conceptos porque determinan el alcance, la configuración y el tipo de evento que puede generar el sistema.

Sensor de imagen CMOSEs el elemento que convierte la luz recibida por la óptica en información digital para formar la imagen.
Sensor PIRDetecta cambios de radiación infrarroja asociados a cuerpos en movimiento. Algunos modelos de cámaras lo integran para apoyar la detección.
Fotocélula / luz ambientalPermite al equipo gestionar cambios entre funcionamiento diurno, nocturno, IR o iluminación auxiliar según el diseño.
MicrófonoEn equipos compatibles permite capturar audio y, según funciones disponibles, generar o complementar eventos.
Entradas de alarmaPermiten conectar contactos o sensores externos compatibles al sistema de cámara o grabador.
Análisis de videoNo es necesariamente un sensor físico: el software analiza la imagen para detectar movimiento, cruce de línea, intrusión, personas o vehículos según el equipo.

Laboratorio técnico

6. Arduino como simulador didáctico de una alerta de seguridad

El HC-SR04 no pretende sustituir los sensores profesionales de una cámara. Se utiliza para que el estudiante comprenda físicamente la lógica de un sistema de seguridad: medir una condición, clasificar el nivel de riesgo y generar una respuesta.

VERDE | NORMAL

Distancia mayor a 15 cm. LED verde encendido. Sin sonido.

AMARILLO | PRECAUCIÓN

Más de 7 cm y hasta 15 cm. LED amarillo y aviso corto/intermitente.

ROJO | ALERTA

7 cm o menos. LED rojo y buzzer continuo de mayor frecuencia.

9. Secuencia de montaje

Conectar 5 V y GND del Arduino a las líneas de alimentación de la protoboard.
Conectar HC-SR04: VCC a 5 V, GND a GND, TRIG a D9 y ECHO a D10.
Conectar los tres LED mediante resistencias de 220 Ω a D2, D3 y D4.
Conectar el buzzer piezoeléctrico al pin D6 y GND.
Revisar el circuito antes de energizar. Cargar el programa.
Abrir Monitor Serial a 9600 baudios y comprobar las distancias.
Probar las tres zonas: normal, precaución y alerta.

10. Programa completo Arduino UNO

const int TRIG = 9;
const int ECHO = 10;
const int LED_VERDE = 2;
const int LED_AMARILLO = 3;
const int LED_ROJO = 4;
const int BUZZER = 6;

float medirDistancia() {
  digitalWrite(TRIG, LOW);
  delayMicroseconds(2);
  digitalWrite(TRIG, HIGH);
  delayMicroseconds(10);
  digitalWrite(TRIG, LOW);

  long tiempo = pulseIn(ECHO, HIGH, 30000);
  if (tiempo == 0) return -1;
  return tiempo * 0.0343 / 2.0;
}

void apagarSalidas() {
  digitalWrite(LED_VERDE, LOW);
  digitalWrite(LED_AMARILLO, LOW);
  digitalWrite(LED_ROJO, LOW);
  noTone(BUZZER);
}

void setup() {
  pinMode(TRIG, OUTPUT);
  pinMode(ECHO, INPUT);
  pinMode(LED_VERDE, OUTPUT);
  pinMode(LED_AMARILLO, OUTPUT);
  pinMode(LED_ROJO, OUTPUT);
  pinMode(BUZZER, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  float distancia = medirDistancia();
  apagarSalidas();

  if (distancia < 0) {
    Serial.println("ERROR: sensor sin lectura");
    delay(300);
    return;
  }

  Serial.print("Distancia: ");
  Serial.print(distancia);
  Serial.println(" cm");

  if (distancia > 15) {
    // NORMAL
    digitalWrite(LED_VERDE, HIGH);
  }
  else if (distancia > 7) {
    // PRECAUCION: amarillo + aviso moderado/intermitente
    digitalWrite(LED_AMARILLO, HIGH);
    tone(BUZZER, 1200, 120);
    delay(220);
  }
  else {
    // ALERTA: rojo + aviso fuerte/continuo
    digitalWrite(LED_ROJO, HIGH);
    tone(BUZZER, 2000);
  }

  delay(180);
}
Interpretación: la distancia funciona como variable de entrada; Arduino toma la decisión; los LED representan el estado y el piezo comunica acústicamente el nivel de riesgo.

11. Caso resuelto: acceso restringido

Situación: se desea representar un perímetro de seguridad. Cuando una persona se aproxima, el sistema debe cambiar progresivamente el nivel de alerta.

Solución: a más de 15 cm permanece verde; entre 7 y 15 cm cambia a amarillo con sonido breve; a 7 cm o menos cambia a rojo y mantiene una alarma continua.

Relación con CCTV: una cámara o sistema real podría asociar un evento de intrusión con grabación, notificación, luz o sirena, dependiendo de sus capacidades.
